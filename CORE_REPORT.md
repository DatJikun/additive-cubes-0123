# Self-sustaining core of the ACF language

**Retraction.** An earlier version of this file answered the mission with “no finite-memory core exists,” citing periodic points of recurrent graphs (Theorem AI). That is true only for the *all-paths* object, and the brief already forbade periodic letter cycles. A finite-state generator with *aperiodic* output (Thue–Morse on a branching k-mer graph, a transducer, a two-operator injection) is a different object. Theorem AI does not kill it. The headline was a dodge.

**Question.** Can we extract from the finite ACF language a self-sustaining infinite core — a finitely representable state whose aperiodic runs stay globally ACF?

**Answer, now.**

- **All-paths recurrent graphs:** impossible (Theorem AI). ELEMENTARY; already known. Not the target.
- **Deterministic finite-state, no external input:** eventually periodic, hence cubes (Theorem AJ). ELEMENTARY.
- **The natural branching k-mer core driven by Thue–Morse (and paperfold / Sturmian):** **dies immediately.** Exhaustive: every TM-walk in the min-outdegree-2 subgraph of the ACF n-mer overlap graph cubes by length 22 (n=5), 23 (n=6, all 3152 starts), 24 (n=7, all 11468 starts), **37 (n=8, all 41998 starts)**. Dual C++/Python on explicit witnesses. This *is* a finite-state generator with aperiodic output. It is not a core.
- **Uniform two-letter operators on all n-mers:** do not exist (Theorem AN).
- **Nested palindrome / doubling templates from short seeds:** die (Theorem AO).
- **Up-and-Down as a nested block recurrence:** false (Theorem AP).

No infinite ACF word was constructed. No positive-entropy theorem was proved. The infinite problem remains **open**.

What remains unkilled as a core: a *different* finite state than last-n letters (danger profiles with a genuine invariant, graph-directed substitutions with a boundary-cube certificate, two-operators on a proper subset closed by something other than the n-mer 2-core), or unbounded memory.

## 0. What this attack is not

It does not rediscover unique-vote, length-14 dead-ends as a census, \(B(2)=119\), \(B(3)=1647\), the Cassaigne lattice, Krylov quotients, triple graphs, bounded \(p_T\), automaticity, or generic \(k\)-regular zero-sets.

Unique-vote is used only as the already-proved \(O(n)\) oracle for the forbidden letter \(F_w(d)\).

## 1. The object that was requested

For a finite ACF word \(w\), write \(E(w)\) for the legal one-letter extensions and \(q(w)=|E(w)|\). A compressed state \(\sigma(w)\) was asked to satisfy:

1. \(\sigma(w)\) is finite or finitely representable;
2. future legality is controlled from \(\sigma(w)\);
3. every state in a recurrent component has a safe outgoing edge;
4. **every path generated by the component is globally ACF.**

Condition 4 as written kills every recurrent graph by Theorem A (periodic paths). The brief also asked for a **branching recurrent automaton with aperiodic output**, and said a state cycle is allowed if the abstraction loses information. That second object is not Theorem AI. It is tested in §16.

## 2. Theorem AI — no recurrent all-paths core

**Status: PROVED** (elementary). Novelty: ELEMENTARY / KNOWN. **Not the mission’s aperiodic target.**

Let \(G\) be a finite directed graph with edges labelled by letters of a nonempty alphabet. Suppose \(G\) is recurrent (some strongly connected component with at least one edge) and every infinite path is ACF.

Recurrence supplies a cycle. Let \(u\) be the concatenation of labels around that cycle, \(u\neq\varepsilon\). The infinite path that repeats the cycle is the purely periodic word \(u^\omega\), which contains the factor \(uuu\). That factor is an ordinary cube of block length \(|u|\), hence an additive cube.

**Contradiction.** Therefore no such graph exists, on \(\{0,1,2,3\}\) or on any other alphabet.

**Computational certificate.** The overlap graph of ACF \(n\)-mers is a concrete instance: nodes are ACF words of length \(n\), with an edge \(v\xrightarrow{a}v'\) when \(va\) is ACF and \(v'\) is its length-\(n\) suffix. This graph is highly cyclic (`suffix_graph.cpp`: one SCC at \(n=8,10\)). One cycle at \(n=6\) has period `001`; `001001001` has cube \(d=3\). One cycle at \(n=8\) has period `200100100`; the triple has cube \(d=9\). Reproduce: `./bin/core_scan cycle 6` and `cycle 8`. Independent: `python3 python/core_verify.py` on \(u^3\).

A state cycle whose *letters* repeat is periodic. A branching state with an aperiodic choice sequence is not. That is Theorem AR, not Theorem AI.

## 3. Theorem AJ — deterministic finite-memory strategies die

**Status: PROVED** (elementary). Computational sharpening: COMPUTATIONALLY VERIFIED.

A deterministic finite-state next-letter strategy is a finite set of states, a start state, and maps \(\delta(s)\in A\), \(\tau(s)\) a new state. The output is eventually periodic (pigeonhole on states). Theorem A: not ACF.

**k=1 exhaustive census.** All \(4^4=256\) maps “next letter = \(f(\)last letter\()\)”, all four seeds: maximum ACF prefix **11**; none reach length 100. Reproduce: `./bin/core_scan detfsm`. Independent: the constant map \(f\equiv 0\) produces `000` at length 3.

A *nondeterministic* finite automaton does not escape Theorem AI if every path must be ACF. If only *some* path must be ACF, a choice rule is required. A finite-state choice rule is Theorem AJ. An external aperiodic driving sequence is a morphic coding.

## 4. Theorem AK — finite macro-block systems are Theorem AI at larger scale

**Status: PROVED** (elementary). Empirical kill of “repeatable blocks from long words”: COMPUTATIONALLY VERIFIED.

Let \(B_0,\dots,B_r\) be finite blocks and \(H\) a finite directed graph with edges labelled by those blocks. A cycle of \(H\) with total letter-length \(L\) produces, by repetition, an ordinary cube of block length \(L\). Cases A–C of boundary cubes (inside one block, crossing one or two boundaries) are irrelevant: the cycle already supplies case “many boundaries”, and it is an *ordinary* cube, not a subtle additive coincidence.

**Empirical.** On the period-1000 Up-and-Down word, the four most frequent 8-mers: all \(4^3=64\) concatenations of length 3 cube (`macro3 acf 0`). Tripling the top 8-mer gives \(d=8\). For \(L=16\) and \(L=32\), 4 of 64 mixed triples stay ACF and 60 cube; the 4 survivors do not include a loop (a loop would force some \(B_i B_i B_i\)). The first cube in a 32-mer triple can have \(d<32\) (witness \(d=17\)); the aligned \(d=32\) cube is still present (block sums \(78,78,78\)).

Period slices of Up-and-Down are not macro-letters: 65 blocks of length 1000 have **65 distinct Parikh vectors**; the block map is deterministic only because each block occurs once (a path, not a cycle). Period 2000: 200 distinct Parikh vectors, 200 blocks. Adjacent blocks are never exact reversals.

## 6. Candidate B — two-branch within \(R\) — false as a universal statement, true on short live words

Length-14 dead-ends have no descendant of any length. Candidate B is **false** for all \(n\), any \(R\).

Restricted to words that are not already dead:

- every ACF 7-mer two-branches at \(r=1\) (11468/11468);
- every ACF 8-mer two-branches by \(r=2\) (42070/42070; the 72 \(q=1\) words need \(r=2\));
- 20k lex 10-mers: all two-branch by \(r=2\).

This is **not** a closed core: it does not propagate past dead-ends, and it does not give operators that compose for all \(n\).

**Uniform operators.** There do not exist two fixed words \(u,v\) of length \(r=1\) that extend *every* ACF 4-mer or 5-mer, nor two ACF 2-mers that extend every ACF 6-mer (best 2738/3152). Reproduce: `./bin/core_scan ops 5 1` and `ops 6 2`; Python on 4-mers: best letter-pair 204/228.

**Good extensions \(q(wa)\ge 2\).** For \(n\le 7\) every ACF \(n\)-mer has at least two children with \(q\ge 2\). At \(n=8\) this fails for exactly the 72 \(q=1\) words (`inject 8`: `eq1 72`). At \(n=9\): 262; \(n=10\): 966 words with only one such child. No infinite two-operator injection was found.

## 7. Dead-end basins — leaves, not a collapsing trunk

The 8170 length-14 dead-ends have **8170 distinct length-13 prefixes** (no prefix owns two dead children). Every such prefix has at least one *live* length-14 sibling. Total live siblings: **22178**.

So the length-14 dead-ends are isolated leaves hanging off prefixes that also continue. They are not the mouth of a basin that swallows every continuation of a positive-density family of shorter words. “Every natural strategy enters the basin” is false for the exact notions “all continuations” and “the unique 13-prefix”: those prefixes are not doomed.

A later dead-end at length 38 shows that new leaves keep appearing. The \(p=1000\) Up-and-Down archive of length 65986 and the fixed-order word of length 24396 are themselves right-crucial (\(q=0\) at the last letter; dual Python). They are not “budget-limited survivors”.

The cap-400000 period-2000 and period-5000 words are different: tail \(q=1\) and \(q=3\) respectively. Those two archives are cap-limited, not dead.

## 9. Up-and-Down is not a recursive block map

Longest common prefixes of the archived constructions:

| pair | LCP |
|---|---|
| \(p=100\) vs \(p=1000,2000,5000\) | 101 |
| \(p=1000\) vs \(p=2000\) and \(p=5000\) | **1000** |
| \(p=2000\) vs \(p=5000\) | **2000** |
| any Up-and-Down vs fixed-order | 0 |

Larger reversal period extends the smaller one through *exactly one* period (the first “down” phase of common priority), then the searches diverge. There is no nested rule \(W_{n+1}=F(W_n)\) relating successive periods, no reversal of adjacent period-blocks, and no recurrent Parikh types.

The construction is chronological backtracking with a periodic priority. Memory is the stack of unused letter-indices — unbounded in the worst case. That is a procedure, not a finite-state or S-adic generator.

## 10. Recursive templates — all short seeds die

From every ACF seed of length 2, 3, or 4 (304 seeds), the maps

- \(W\mapsto WW\),
- \(W\mapsto WxW\) (\(x\in\{0,1,2,3\}\)),
- \(W\mapsto WxW^R\),
- \(W\mapsto WW^R\)

all produce an additive cube before length 256. Best palindrome-fold ACF prefix: length 9 (`0010` with separator 2). \(WW\) iterated twice contains \(W^4\), hence \(W^3\).

No Toeplitz / nested-reversal / paperfold generator was found that is infinite by construction. This is a finite-seed census, not a proof that every growing recursive template fails.

## 11. Random walk and the two-smallest tree

Uniform random legal letters: survival \(0.918\) to depth 80 (8000 trials) and \(0.813\) to depth 120 (4000 trials). The drop is compatible with a per-step death chance on the order of \(10^{-3}\), not with a positive limiting survival probability. This is **not** a random infinite ACF process.

Two-smallest branching (`grow2`): a 2-ary unfolding with frontier capped at 4096 reaches depth 50 with 320 observed deaths, **first death at length 14**. That strategy is not a closed core; it walks into the known leaves.

## 15. The central question

**Is there now a mathematically defensible mechanism that can keep extending ACF words forever?**

**Not from the all-paths sofic object, and not from the ACF n-mer 2-core driven by Thue–Morse / paperfold / Sturmian for \(n\le 8\).**

The first of those was never a new mechanism. The second is the finite-state aperiodic generator the brief actually asked for, built from the finite ACF language itself. It cubes by length 37.

A different compressed state (danger-profile hashes that are not last-n letters, a closed two-operator family with a boundary certificate, a graph-directed substitution with an invariant) was not found and was not proved impossible. Up-and-Down remains a long finite procedure with unbounded stack memory, not a core.

## 16. Theorem AR — Thue–Morse on the ACF n-mer 2-core

**Status: COMPUTATIONALLY VERIFIED.** Novelty: UNVERIFIED NOVELTY as a construction-attack; the 2-core itself is an elementary graph-theoretic subset of the overlap graph.

Let \(G_n\) be the overlap graph of ACF n-mers. Delete vertices until every remaining vertex has at least two outgoing edges into the remainder (the maximum subgraph of minimum out-degree 2). From any remaining n-mer, walk by taking the Thue–Morse bit of the step index modulo the number of remaining out-edges, ordered by letter.

| n | 2-core size | starts exhausted | max ACF length | best start |
|---|---|---|---|---|
| 5 | 864 | all 864 | 22 | `00100` |
| 6 | 3152 | all 3152 | 23 | `001010` |
| 7 | 11468 | all 11468 | 24 | `0010011` |
| 8 | 41998 | all 41998 | **37** | `00131022` |

Lex-start n=6 TM witness (prefix ACF, last letter cubes):
```
001001021010031002011
```
Cube \((i,d,\mathrm{sum})=(6,5,4)\). Dual Python `find_cube`.

Lex-start n=8:
```
0010010021101003100201103002011013
```
Cube \((7,9,8)\). Dual Python.

Paperfold n=6, 200 starts: max 29. Sturmian n=8, 200 starts: max 32. Even the *legal* variant (global unique-vote oracle, TM among 2-core letters when possible) dies at length 160 from the lex n=8 start — and that variant is **not** finite-memory.

Reproduce:
```

./bin/core_scan drive 8 tm 1000 blind
./bin/core_scan dscan 8 tm 80 50000
python3 python/core_verify.py
```

This kills last-n-letter branching automata driven by these three binary automatic sequences, for \(n\le 8\). It does not kill every transducer, every k>8, or every other driver.

## 17. Macro-letters: two ACF blocks coded by Thue–Morse

**Equal length — Theorem AS, PROVED.** Novelty: ELEMENTARY.

Thue–Morse on \(\{0,1\}\) begins `0,1,1,0,1,0`. Substituting blocks \(u,v\) of equal length \(L\) produces
\[
uv\,|\,vu\,|\,vu.
\]
The three blocks of length \(2L\) have sums \(\sum u+\sum v\), \(\sum v+\sum u\), \(\sum v+\sum u\). These are equal, so there is an additive cube of block length \(2L\) at the start, at letter-length \(6L\). This does not use that \(u,v\) are ACF. It kills **every** equal-length two-block TM coding, including a shift that still contains the factor `011010` (which TM does, at position 0). Offsets 1,3,5,7 of length-4 blocks still all die by length 28 (computational; the same identity may apply after a prefix).

**Unequal length — COMPUTATIONALLY VERIFIED, not a theorem.** All ACF pairs of lengths \((3,5)\) (51840 pairs, six TM offsets), \((3,4)\), \((2,5)\), \((2,6)\), and samples of \((4,5)\), \((4,6)\), \((3,7)\): none reach length 40. Paperfold is worse. Best observed: 30.

So the next finite-memory idea after letter automata — “take two safe blocks and play Thue–Morse” — also dies for small blocks. Larger unequal blocks are not exhausted.

Reproduce: `./bin/core_scan tmblocks 3 3 50 0` (best 18 \(=6\cdot 3\)); `python3 python/core_verify.py` (Theorem AS).
